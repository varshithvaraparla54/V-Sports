# V² Sports static demo

A static storefront demo made for GitHub Pages. It keeps the product catalog, categories, search, and a browser-local cart.

## Demo limitations

- No account registration or login.
- Checkout is a visual demo only. It does not collect delivery or payment details and does not place orders.
- Contact messages are not sent.
- Cart items stay in the visitor’s browser and are not saved to a shared database.

## Publish with GitHub Pages

Upload the contents of this folder to the root of your GitHub repository. In the repository, open Settings, then Pages, choose Deploy from a branch, select the main branch and root folder, then save. GitHub will show the website address there.
